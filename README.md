# NNTU_python
Учет спортивного инвентаря в зале
Цель работы

Изучить основные этапы создания информационной системы. Научиться описывать её задачи, пользователей и основные функции. Получить навыки создания Use Case диаграмм и блок-схем для наглядного представления работы системы.
Практическая часть
1. Постановка задачи
1.1 Описание предметной области

Предметная область — спортивный зал, в котором необходимо вести учёт спортивного инвентаря. Для автоматизации процессов учёта разрабатывается информационная система «SportTrack».
Основной задачей системы является автоматизация учёта спортивного инвентаря и предоставление пользователям удобного доступа к информации о доступном оборудовании.

1.2 Цели и задачи системы

Целью разработки системы «SportTrack» является автоматизация учёта спортивного инвентаря в спортивном зале.
Для достижения поставленной цели система должна обеспечивать выполнение следующих задач:
    • хранение информации о спортивном инвентаре;
    • хранение информации о категориях спортивного инвентаря;
    • предоставление возможности поиска инвентаря;
    • предоставление возможности просмотра информации об инвентаре;
    • оформление выдачи спортивного инвентаря пользователю;
    • регистрация возврата спортивного инвентаря;
    • управление информацией о спортивном инвентаре;
    • управление информацией о категориях инвентаря;
    • управление учётными записями пользователей;
    • просмотр информации о выданном инвентаре;
    • авторизация пользователей в системе.
    
1.3 Пользователи системы (актеры) и их роли

1. Администратор
Администратор отвечает за управление системой и учёт спортивного инвентаря.
Администратор может:
    • авторизоваться в системе;
    • добавлять спортивный инвентарь;
    • изменять информацию об инвентаре;
    • удалять инвентарь из системы;
    • добавлять категории инвентаря;
    • изменять категории инвентаря;
    • удалять категории инвентаря;
    • просматривать список пользователей;
    • регистрировать пользователей;
    • просматривать информацию о выдаче инвентаря;
    • регистрировать возврат инвентаря.
2. Пользователь
Пользователь использует систему для поиска и получения спортивного инвентаря.
Пользователь может:
    • авторизоваться в системе;
    • просматривать список спортивного инвентаря;
    • искать спортивный инвентарь;
    • просматривать подробную информацию об инвентаре;
    • оформлять выдачу доступного инвентаря;
    • просматривать список выданного ему инвентаря.

1.4 Основной функционал

Функции пользователя
    1. Авторизация — вход пользователя в систему с использованием логина и пароля.
    2. Просмотр инвентаря — просмотр списка спортивного оборудования.
    3. Поиск инвентаря — поиск необходимого оборудования по названию или категории.
    4. Выдача инвентаря — оформление получения доступного спортивного оборудования.
    5. Просмотр выданного инвентаря — просмотр пользователем списка оборудования, которое ему выдано.
Функции администратора
    7. Добавление инвентаря — добавление новой единицы спортивного оборудования в систему.
    8. Изменение инвентаря — изменение информации о существующем оборудовании.
    9. Удаление инвентаря — удаление информации об оборудовании из системы.
    10. Регистрация пользователя — создание новой учётной записи пользователя.

1.5 Архитектура проекта

Для разработки информационной системы «SportTrack» используется трёхуровневая архитектура. Система состоит из трёх основных уровней.
    1. Слой интерфейса
Слой интерфейса обеспечивает взаимодействие пользователя и администратора с системой. Через интерфейс пользователь может авторизоваться, просматривать и искать инвентарь, просматривать его характеристики и оформлять выдачу. Администратор через интерфейс может управлять инвентарём, категориями, пользователями и операциями выдачи и возврата.
    2. Слой бизнес-логики
Слой бизнес-логики отвечает за выполнение основных операций системы. Он проверяет корректность введённых данных, определяет доступность спортивного инвентаря, обрабатывает выдачу и возврат оборудования, а также контролирует права доступа пользователей в соответствии с их ролями.
    3. Слой данных
Слой данных предназначен для хранения информации системы. В базе данных хранятся сведения о спортивном инвентаре, категориях, пользователях и операциях выдачи и возврата.
